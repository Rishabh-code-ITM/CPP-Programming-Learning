# CPP-Programming-Learning

C++ seekhne ke liye beginner se intermediate level ke programs. Har line par Hindi-English mix comment hai, taaki code samajhna aasaan ho.

## Folders (Topics)

| # | Folder | Kya seekhenge |
|---|--------|---------------|
| 01 | Basics | Hello World, comments, escape sequences |
| 02 | Variables-Data-Types | Variables, data types, constants, sizeof |
| 03 | Input-Output | cin, cout, getline |
| 04 | Operators | Arithmetic, relational, logical, assignment, increment/decrement |
| 05 | Conditional-Statements | if, if-else, else-if, nested if |
| 06 | Switch-Case | switch, calculator, menu driven program |
| 07 | Loops | for, while, do-while, nested loops |
| 08 | Loop-Control | break, continue |
| 09 | Functions | Parameters, return value, overloading |
| 10 | Arrays | Array basics, sum, largest, linear search |
| 11 | Strings | string class, input, length, reverse |
| 12 | Pointers | Pointer, address, dereference, reference |
| 13 | Object-Oriented-Programming | Class, constructor, encapsulation, inheritance, polymorphism |
| 14 | STL | vector, pair, set, map |
| 15 | Problem-Solving | Number, pattern aur logic problems |

## Kaise Run Karein

```bash
g++ Hello_World.cpp -o hello
./hello
```

Windows par: `g++ Hello_World.cpp -o hello.exe` ke baad `hello.exe`.

## Comment Style

- Jo cheez sabko pata hai (jaise `return 0;`), wahan simple English comment.
- Jahan concept samjhana hai, wahan Hindi + English dono.

## Tips

1. Pehle code padho, fir khud likh ke run karo.
2. Values badal ke dekho ki output kaise badalta hai.
3. Har topic ke baad apna ek chhota program banao.

Happy Coding!
